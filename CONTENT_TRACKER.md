### Dossier source audit — 2026-11-03
All four dossiers were checked against the papers they cite, and **every remaining `biological_mechanism` line was misattributed**. Full texts loaded, not abstracts.

- **`loss_aversion`** — Kahneman & Tversky 1979, *Econometrica* 47(2), 263-291 contains no imaging; the method is hypothetical questionnaires (p. 264) and loss aversion is a functional claim about the value function (p. 279). The real scans are De Martino et al. 2006, *Science* 313(5787), 684-687 (amygdala tracks **frame-congruent choices**, "rather than the valence of the frame per se", p. 686) and Knutson et al. 2007, *Neuron* 53(1), 147-156 (insula responds to **excessive prices**, p. 147). "The exact circuits processing physical tissue damage" was an overstatement in all three directions. Mechanism line now states only the 1979 claim.

## 6. Production & Upload Checklist (For Every Video)

### Part A: Create & Render
1. Initialize blueprint + upload kit:
   ```bash
   python tools/pipeline.py --topic "Topic" --id SH-XX --slug short_xx_topic
   ```
2. Customize `project.json` and `UPLOAD_KIT_*.md`: 8–12 scenes, 105–155 words, verified dossier only, no static angle over 3.5 s.
3. Build:
   ```bash
   python tools/pipeline.py --build shorts/<slug>/project.json
   ```
4. Quality gate:
   ```bash
   python tools/pipeline.py --verify-all
   ```

### Part B: Upload
```bash
.venv/bin/python tools/pipeline.py --upload-api shorts/<slug>
.venv/bin/python tools/pipeline.py --sync-stats
```

### Part C: Studio Touchpoints (Post-Upload)
1. **Title:** use the primary high-CTR title from the upload kit; never put `#shorts` on a 16:9 Long-Form.
2. **Related Video (Shorts):** Studio → Video Details → Related Video → `LV-02` (*The 3 Hidden Brain Traps Destroying Your Focus*).
3. **Pinned Comment:** pin the topic-specific question; heart and reply to real viewer comments in the first hour.
4. **Visibility:** upload Unlisted → wait 10–15 min for 1080p VP09 → switch to Public.
