# requirements-optional.txt - heavy / feature-gated dependencies
#
# Every package here is imported LAZILY inside tools/*.py (inside a function, usually
# inside try/except). Missing one does NOT break `import tools.*` or the test suite;
# it silently downgrades exactly the feature named under it. Versions are pinned to what
# is installed in .venv today, so `pip install -r requirements-optional.txt` reproduces
# this machine rather than a guess.
#
# Installed-but-unused honesty note: depthflow==1.0.1 IS present in this venv, but no file
# under tools/ imports it. The `depthflow_spiral` / `depthflow_vertigo` / ... strings in
# genre_director.py and project.json are preset NAMES; the parallax motion is computed by
# tools/visual_engine.py with torch + transformers. Kept below under [3d] for that reason,
# and flagged as "not imported by tools/" so nobody deletes it thinking it is dead weight
# without checking Blender/CLI usage first.
