## What failed and what changed

| Area | Confirmed problem | Edit |
| --- | --- | --- |
| Master task results | Critical audit findings could still produce a successful worker result. Resume trusted file existence and could leave a passed descendant after an input changed. | Critical audit findings now fail. Local artifacts receive SHA-256 fingerprints, changed inputs invalidate descendants, and completed approval-required actions or strict releases enter persistent reconciliation instead of silently rerunning. Only the build's declared `project.json` output can refresh an ancestor hash after a verified build mutation; older hashless run records are revalidated. |
| Release and upload | Legacy CLIs called the uploader without reviewed evidence; ordinary `produce --publish` used a warning-level gate. A custom workflow could label a release strict while omitting its verifiers and still reach upload. | `pipeline.py`, `upload_api.py`, and `agents.py` compatibility commands require evidence and explicit `--yes` and delegate to `release-existing`. The publisher checks the complete seven-verifier strict-release contract, fingerprints, dependency, and approval before calling the uploader. Ordinary `produce --publish` now fails with instructions to release the completed project separately. The publisher passes the reviewed project's synthetic-media declaration. |
| Media validation | One existing asset could hide a missing selected shot. A promoted video could be rejected because its source image was absent. Stream presence alone marked an MP4 valid even with the wrong codec, dimensions, frame rate, audio, container, or duration. | Pre-compose checks every renderer-selected visual source, including generated video substitutions. MP4 validation checks MP4/H.264, target dimensions, 30 fps, AAC at 48 kHz, and a finite duration of at least five seconds before returning `valid=True`. Failed command stages now return nonzero exit codes. |
| Research and script | Incomplete dossiers could lead to invented narration. Topic lookup could pick the first partial study match. Numeric claims used loose substrings, metadata URLs, or an exempt five; title and script wording rules disagreed. | Missing grounding fields stop generation. A shared dossier lookup prefers exact key/topic matches and rejects ambiguous partial matches. Numeric support uses exact tokens from factual fields or scene-bound claims. Title and script checks share one case-insensitive, whole-word voice blacklist; title packaging checks reach pre-compose validation. |
| Transcript and chapters | The transcript APIs duplicated parsing behavior, crashed on malformed JSON text/timestamps, counted overlapping cuts twice, and could infer dead air inside overlapping speech. Chapters could use the wrong final duration or accept invalid boundaries. | One cue loader and EDL analysis path now handles SRT, VTT, and Whisper JSON, rejects invalid/nonfinite timing, computes the union of proposed cuts, and tracks the maximum covered speech end. Chapter generation uses the maximum cue end and validates whole-second starts and ten-second minimum chapters. Inline filler remains a manual-review case because cue timing cannot locate a word inside speech. |
| Consistency and repeated code | The impact index could miss an unknown workflow dependency or flag a valid dynamic one. CLI and API outlier rankings disagreed at a rounded threshold. Two helper functions had no production callers. | Dependency references are checked within the declaring workflow/factory scope, with dynamic lists left to runtime DAG validation. CLI and API outliers share one raw-ratio filter and round only for display. Removed the unused uploader duration probe and unused project JSON parser; removed their obsolete test patch. Shared dossier lookup, transcript handling, and blacklist rules replace duplicated logic. |
| Reporting and docs | A missing status or invalid MP4 could print PASS, overlong table cells broke alignment, and several citations and live workspace descriptions were stale. Hook formula labels repeated scores that no longer matched the scorer. | Unknown/invalid states no longer print PASS; tables wrap cells. Updated `README.md`, `GEMINI.md`, the orchestrator and API guides, historical citation notes, and the dossier labels. Computed hook scores remain owned by the scorer. |
